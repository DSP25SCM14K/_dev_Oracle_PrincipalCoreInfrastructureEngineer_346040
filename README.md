# Dev Kumar — AI Infrastructure Portfolio

A static portfolio focused on distributed systems, GPU/server operations, OCI/AWS data planes, high-speed networking, and reliability engineering.

## Files

- `index.html` — portfolio content, animated system map, experience, projects, and research links
- `styles.css` — responsive visual system and motion/reduced-motion styles
- `script.js` — animated network background, rotating focus text, reveal effects, and project search
- `ROLE_RESEARCH.md` — Oracle/OCI role research, resume evidence map, and interview-preparation themes

## GitHub Pages

No build step is required. Enable Pages from repository settings with **Deploy from a branch**, `main`, and `/(root)`.
